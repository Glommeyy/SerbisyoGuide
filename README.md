# SerbisyoGuide

Initial structure for a barangay service information and requirements checker.

Open `index.html` in a browser. Tailwind CSS currently loads from its CDN, so the styled prototype requires an internet connection.

## Files

- `index.html`: Responsive page structure and placeholder sections.
- `styles.css`: Small custom styles and accessibility adjustments.
- `script.js`: Reserved for future interactions; no application functions yet.

The service controls are intentionally disabled. Personalized questionnaires, JSON service data, checklist tracking, localStorage, and printing are deferred. No database or accounts are used.

All service information is illustrative. Partner barangay requirements and office details must be verified before deployment.
